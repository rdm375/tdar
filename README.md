# TDAR

**Taylor-Disagreement Adaptive Refinement** is a derivative-informed adaptive sampling method for constructing piecewise-linear surrogates of smooth scalar functions on a two-dimensional unit-square domain.

This repository is the clean reusable implementation of the frozen **TDAR method v1**. Research history, benchmark oracles, diagnostic experiments, and earlier algorithm generations remain in the separate `adaptive-surrogates` research repository.

## Method

TDAR uses automatic-differentiation gradients only to decide **where to sample**. The resulting surrogate remains piecewise linear. Each refinement batch combines:

- Taylor-model disagreement at triangle centroid and edge-midpoint probes;
- Taylor disagreement on convex-hull boundary edges;
- a unified triangle/boundary priority queue;
- scale-aware boundary closure;
- local maximin point placement with a minimum-separation rule; and
- deterministic global farthest-point filling when an adaptive batch cannot be filled.

The default `TDARConfig` is the frozen method-v1 configuration: 16-point initial design, batches of 8, order-12 maximin lattices, 0.10 minimum separation, closure ratio `1e-2`, 16,384 fill candidates, and seed 12345.

## Quick start

```python
import jax.numpy as jnp
from tdar import farthest_point, sample

def f(x):
    return jnp.exp(-40.0 * ((x[0] - 0.35)**2 + (x[1] - 0.6)**2))

initial = farthest_point(16)
result = sample(f, initial, budget=128)
print(result.points.shape)
```

`f` must be a JAX-differentiable scalar function accepting a point of shape `(2,)`.

## Scope

TDAR v1 is intentionally narrow: scalar functions, two independent variables, unit-square domain, first derivatives available through JAX, Delaunay triangulation, and a piecewise-linear downstream surrogate. General domains, vector-valued functions, higher dimensions, and alternate derivative providers are future API work rather than silently generalized here.

## Reproducibility

The production sampler contains no true-error oracle and does not evaluate the target away from accepted sample points. Regression tests compare the extracted implementation against frozen reference point sets generated by the research implementation.
